เรียนทีม BKI Web Partner API

Kladee Broker ทดสอบ UAT แล้ว รบกวนช่วยตรวจสิทธิ์ account ครับ

■ Environment: UAT
■ URL: https://bkiwpapiuat.bangkokinsurance.com/vol/premium/calculate
■ Method: POST
■ Authen: Basic Auth

■ ข้อมูลที่ใช้
- REST Basic Auth user: 03477
- user_id (param): 03477
- agent_code (param): 3477
- agent_seq (param): 00

■ Server IP ที่ลงทะเบียน (Allowed IP)
- 14.207.141.5
- 203.170.129.135

■ ผลทดสอบจาก server (IP whitelist แล้ว)
- ถึง API ได้ (ไม่โดน CloudFront)
- HTTP Status: 401
- ERR_CODE: API000_F_T0001
- ERR_MSG: Fail - Authorization has been denied for this request

■ หมายเหตุ
- ทดสอบจาก IP นอก whitelist (เครื่อง dev) ได้ 403 CloudFront — เป็นปกติ
- ทดสอบจาก server production ที่ whitelist แล้ว ถึง API ได้ แต่ Authorization ไม่ผ่าน

■ คำถาม
1. REST password ของ user 03477 สำหรับ UAT ยังใช้ได้หรือไม่
2. account / user_id / agent เปิดใช้งานครบแล้วหรือยัง
3. ต้องใช้ environment UAT หรือ SIT

[5] อ่านผลลัพธ์
--------------------------------------------------------------------------------

HTTP 403 + HTML CloudFront     → IP ไม่อยู่ whitelist
HTTP 401 + API000_F_T0001      → ถึง BKI แล้ว แต่ Basic Auth ไม่ผ่าน
HTTP 400/422 + validation      → Auth ผ่านแล้ว (body ยังไม่ครบ)
HTTP 200                       → สำเร็จ
